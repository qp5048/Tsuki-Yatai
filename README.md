# Zakharii — web projects

Portfolio of websites designed and built by **Zakharii**.
Live: **https://qp5048.github.io/Tsuki-Yatai/**

| Project | What it is | Built with |
|---|---|---|
| [Tsuki Yatai](tsuki-yatai/) | Night-market noodle bar. Scroll-driven 3D bowl, live bowl builder, menu with quick view, ordering flow, table booking. | Three.js, GSAP ScrollTrigger, Lenis, vanilla JS |
| [Hearthnet](hearthnet/) | A studio that builds small, 90s-style social networks. Organic / natural design system, working guestbook, visitor counter. | HTML, CSS, vanilla JS, Lucide icons |
| [Valvskolan](skolan/) | A Stockholm F–9 school styled as a painted metro station. Five pages: live departure-board timetable, lunch menu with allergen marking, filterable calendar with .ics export, news with search, staff directory and visit booking. | HTML, CSS, vanilla JS (ES modules), generative SVG |

Everything is plain HTML, CSS and JavaScript: no framework and no build step.
Both businesses are fictional; names, people and prices are made up. Photos from Unsplash.

## Run locally

```bash
python -m http.server 8000   # then open http://localhost:8000
```
